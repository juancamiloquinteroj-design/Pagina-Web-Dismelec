Token de GitHub

Se guarda SOLO en este navegador -- nunca se manda a ningún lado más que a GitHub.

Generalo en github.com/settings/tokens/new -- tipo "classic", marcá el permiso repo completo, sin fecha de vencimiento corta si querés no repetir esto seguido. Pegalo acá abajo una sola vez.
